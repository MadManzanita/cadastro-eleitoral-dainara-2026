# Cadastro Eleitoral • Coordenadora Dainara Torres

Protótipo frontend responsivo, pronto para ser colocado em um repositório GitHub e publicado na Vercel.

## Estrutura
- Dashboard
- Lideranças
- Detalhes da liderança
- Ativistas vinculados
- Novo cadastro de liderança
- Novo cadastro de ativista
- Configurações
- Exportação CSV
- Persistência local para demonstração

## Importante
Esta versão é um protótipo frontend. Os dados ficam no `localStorage` do navegador. Não use o protótipo para armazenar dados pessoais reais antes de implementar autenticação, banco de dados, controle de acesso, política de privacidade e demais medidas de segurança apropriadas.

## Deploy
1. Crie um repositório no GitHub.
2. Envie `index.html` e este `README.md`.
3. No Vercel, importe o repositório.
4. Como é um site estático, não é necessário build command.
