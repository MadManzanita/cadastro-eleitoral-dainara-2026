# Cadastro Eleitoral • Coordenadora Dainara Torres

Protótipo frontend responsivo, compatível com hospedagem estática/Vercel.

## Publicar no GitHub

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para o repositório.
3. No Vercel, importe o repositório.
4. Para este protótipo não é necessário banco de dados ou build command.

## Observação

Esta versão é apenas um protótipo visual e armazena dados no `localStorage` do navegador. Não use dados pessoais reais em produção antes de implementar autenticação, banco de dados, controle de acesso, políticas de retenção e medidas de segurança adequadas.
