# Diretriz de oficialização

## Identidade visual

- Manter a paleta rosa suave como assinatura, em uso pontual e sóbrio.
- Priorizar branco, grafite e tons neutros para transmitir confiança e organização.
- Usar tipografia limpa, hierarquia bem definida e cartões discretos.
- Empregar uma linguagem institucional, clara e acolhedora.

## Acesso restrito

- Nunca mostrar ou publicar o código de acesso na interface, README ou repositório.
- Armazenar o código apenas na variável privada `RELEASE_CODE` do ambiente de hospedagem.
- A entrega do código será feita pessoalmente pela coordenação.

## Próxima etapa para operação oficial

- Migrar os dados do navegador para um banco protegido (Supabase).
- Implementar contas reais, sessões e permissões no servidor.
- Registrar auditoria de alterações e configurar backups.
